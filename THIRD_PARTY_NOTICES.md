# Third-party components

This project links to libraries through Gradle rather than copying their source code.

- AndroidX / Jetpack Compose / CameraX — Android Open Source Project, Apache License 2.0.
- Google ML Kit face detection and object detection — Google ML Kit SDK terms apply.
- OkHttp — Square, Apache License 2.0.
- Kotlin and kotlinx.coroutines — JetBrains, Apache License 2.0.

No FluxGarage RoboEyes GPL source code is copied into this project. The eye renderer in `RobotFace.kt` is an original Compose Canvas implementation.
